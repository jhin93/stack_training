Week 4 Overview

Lecture:

This week’s lecture covers Advanced Networking and the Dynamic Host Configuration Protocol (DHCP), including:

DHCP concepts and configuration

DHCP operations

DHCP superscopes

DHCP troubleshooting

DHCP server authorization

Please review the Week 4 lecture notes and prerequisite videos before class.

Lab:

This week’s laboratory focuses on configuring DHCP clients and servers on CentOS 10 and Windows Server 2025. Activities include:

Installing and configuring a DHCP server on CentOS 10

Configuring and testing a Windows DHCP client

Creating reserved addresses on Linux

Installing and configuring the DHCP Server role on Windows Server

Configuring and testing a Linux DHCP client

Creating reserved addresses on Windows Server

Complete Lab 4a and Lab 4b during your scheduled lab session.

Videos:

Watch the Week 4 prerequisite lecture videos before class to prepare for the DHCP concepts and practical activities covered this week.
