Week 2 Overview

Lecture

This week's lecture covers Linux and Windows installation and configuration, including system documentation, hardware and kernel configuration, disk partitioning, boot loader installation, software package management (RPM, YUM, and DNF), and process management. Please review the Week 2 lecture notes before class.

Lab

This week's laboratory focuses on practical system administration tasks, including using system documentation, updating Linux and Windows systems, managing processes, controlling jobs, and working with disk partitioning in both operating systems. Complete all Week 2 lab exercises during your scheduled lab.
